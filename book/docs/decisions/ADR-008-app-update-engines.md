# 应用内更新引擎与安装许可

状态：采用，2026-11-23。发布仍由维护者决定。

多开模拟器复用多会话测试浏览器 `ccf53f0` 的更新方案。Mac ARM64 用 Sparkle 和独立 Ed25519 密钥，Windows x64 用 electron-updater 和现有 NSIS。目标仓库的 GitHub Latest 提供稳定清单。Mac appcast 引用固定版本的归档和说明。两平台使用同源版本日志，验证完整资产后才公开草稿。

主进程负责更新状态和安装许可。renderer 只读取状态和发起用户意图。显式确认后关闭冲突操作入口，核对任务、持久化和自有 AVD 的正常停机结果，再交接更新。普通退出沿用当前流程，Mac 在进入该流程前等待 Sparkle 确认取消。正式证书与更新签名各有职责，首轮验收用独立测试密钥、应用身份和数据目录。
