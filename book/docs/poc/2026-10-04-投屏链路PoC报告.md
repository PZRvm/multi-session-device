# 投屏链路 PoC 报告（stage 04 步骤 1 闸门）

> 测试日期：2026-10-04 · 本机：MacBook Pro（Apple Silicon，macOS 15.6，Darwin 24.6.0）
> 结论：**过线**。交互帧率与触摸延迟均显著优于 PRD 验收线（≥30fps / ≤150ms）。

## 链路形态

主进程：spawn headless 模拟器（`-no-window -no-audio -no-boot-anim -no-snapshot -gpu <mode>`）→ adb push scrcpy-server v3.3.3 → `adb shell app_process` 启动 server（`tunnel_forward=true`）→ `adb forward tcp:0` → 裸 TCP 双连接（video + control，forward 隧道 dummy byte 握手）→ H.264 包经 `webContents.send` 送 renderer。
renderer：WebCodecs 硬解（`@yume-chan/scrcpy-decoder-webcodecs`）→ canvas 2D 绘制；触控经 preload → main → scrcpy 控制协议注入（injectTouch Down/Move/Up）。
协议面复用 Tango（@yume-chan/scrcpy 2.3.0 的 options 类：参数序列化、流元数据解析、媒体流变换、控制消息编码）；传输层为 adb forward + 裸 TCP（与官方 scrcpy 客户端同款路径）。

## 实测数据

| 配置 | 分辨率 | 交互 fps | 触摸延迟中位 | P95 | 静置 fps |
| --- | --- | --- | --- | --- | --- |
| host GPU · 全分辨率 | 1080×2400 | **59** | **75ms** | 161ms | 2（静态不出帧） |
| host GPU · maxSize 1200 | 544×1200 | **59** | **68ms** | 126ms | 2 |
| swiftshader_indirect（降级参考） | 1080×2400 | 14 | 223ms | 341ms | 1 |

- 版本对：scrcpy-server v3.3.3 × @yume-chan/scrcpy 2.3.0（Tango 稳定线最高支持 3.3.3）。
- 静置 fps ≈ 0 是 H.264 按内容变化出帧的正常行为，不是链路缺陷。
- 两档分辨率交互 fps 相同（59 ≈ vsync 上限），瓶颈不在像素吞吐；分辨率缩放可作为省带宽的产品选项而非性能手段。

## 测量方法

- **交互 fps**：10s 窗口内背靠背 swipe（滑开/收起应用抽屉交替，单次 250ms，无间隔），计解码输出帧数 ÷ 窗口时长。
- **触摸延迟**：20 次「下拉通知栏 / 上滑收起」短手势（80ms），注入与采样并发（先记 t0 再发注入）；rAF 逐帧对上半屏 ROI（160×200 降采样）做像素差，显著变化像素数 >20（|Δluma|>25）记首变时间。20/20 样本命中，零超时。
- 延迟口径含 IPC 与解码上屏全程；设备侧已关系统动画（window/transition/animator 三个 scale 置 0）。

## 环境与偏差记录

- 本机 SDK：`~/Library/Android/sdk`（emulator 36.1.9，system-images;android-36;google_apis;arm64-v8a），AVD 按目录规范手写 config（pixel_8 画像参数），`ANDROID_AVD_HOME` 隔离到应用数据目录，冷启动 ≈ 9s boot 完成。
- 与 plan 的偏差（详见 plan 完成记录）：avdmanager 因 cmdline-tools 19/20 无法解析 SDK 根而弃用（手写 config 替代）；取流传输从 Tango 的 adb-server 直连改为 adb forward + 裸 TCP；视频包投递从 MessagePort 改为 `webContents.send`。
- 快照恢复路径在本 AVD 上会原生崩溃（crash_report_exception_handler），PoC 固定 `-no-snapshot` 冷启动；快照加速属 v1.1 候选。

## 对后续步骤的输入

1. 步骤 5（投屏产品化）沿用本链路：adb forward + 裸 TCP + Tango 协议面；分辨率默认全档（1080×2400），maxSize 作为可选档。
2. `webContents.send` 每帧拷贝在 8Mbps 下占用可接受；产品化时可再评估 MessagePort（跨 contextBridge 的投递问题先记录在 issue）。
3. 删除运行中设备的 AVD 锁保护、模拟器启动器进程组终止（`detached` + `kill(-pid)`）已在 harness 内验证，步骤 4 runner 直接继承。
