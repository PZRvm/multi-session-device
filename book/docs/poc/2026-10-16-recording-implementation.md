# 录屏开发验证记录

[plan](../../plans/2026-10-16-device-recording.md) 的 Phase 3 已接入产品代码。自动化和构建通过，真实模拟器视频已生成；完整交付尚未通过 Phase 4。两设备十分钟样本最大声画偏差为 **112/106ms**，超过 100ms 目标，Android 13+ 真机声音和交互性能也仍待验。用户已批准真机音频验收后移，未降低同步目标。

## 实现范围

- 模拟器与 USB/无线真机共用录制入口；main 绑定 deviceId/runId/streamId，源订阅在投屏 ACK 流控之前取得原始包。选中设备变化不改变原任务。
- 每设备独立 MP4，设备输出声走独立 playback/dup 会话，不采宿主或麦克风。采音不可用时用原生提示选择无声继续或取消。
- 暂停/续录共用任务，暂停与等待关键帧不计时、不进入视频。连续旋转按设备 PTS 接段；最终最大宽高画布居中留黑边，无旋转兼容配置直接封装。
- 首版最多同时采集 2 个任务、一次生成 1 个文件；写盘和处理 IPC 均有字节预算。编码必须缩小时先提示。
- 系统下载目录保存，重名不覆盖；成功只显示文件名、文件夹定位和关闭。失败保留材料，重启后可重试生成；正常封存材料重试不会被误标为录制中断。
- 主窗关闭不停止任务；真正退出提供停止保存、留在应用、放弃未完成任务三分支。主窗和隐藏媒体页使用不同权限桥。

实际模块见 [架构快照](../architecture/2026-10-16-recording.md) 与 [IPC 契约](../api/2026-10-16-recording.md)。Mediabunny 锁定 **1.61.5**，MPL-2.0 文本随包分发；FFmpeg 只用于测试测量。
