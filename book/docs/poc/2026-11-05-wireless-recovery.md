## 开发窗口实测

环境：macOS 15.8.1、Samsung SM-A155F，经典无线地址 `192.168.31.162:5555`。原应用继续运行；worktree 在 6175 启动，临时绕过单实例锁。

调试 userData 为 `~/Library/Application Support/msd-wireless-dev-6175`，只复制 SDK 来源、主题和语言设置。复用现有 `~/Library/Android/sdk`，未创建模拟器，未复制 SDK 或 AVD 大目录，未让两个进程共写同一份设备元数据。

| 操作 | 观察 |
| --- | --- |
| 无线窗连接 `127.0.0.1:5555`（本机未监听端口） | 显示“无线端口未就绪或未监听”，出现重试/修复/复制诊断；窗口中操作不溢出 |
| 点修复后取消原生确认框 | 提示明确列出共享 ADB、IDE、其他无线设备和端口转发影响；取消后按钮恢复，无服务重启 |
| 再次确认重启并重试 | 实际更换共享 ADB 进程，显示修复中；目标仍不可达时退出并恢复按钮，没有循环重启 |
| 恢复实际手机连接 | `adb connect 192.168.31.162:5555` 成功；无线 shell 输出 `msd-wireless-ready` |
| 无线窗再连接真实手机 | shell 验证通过后窗口关闭，主窗显示 SM_A155F 无线在线 |
| 结束开发验证 | 停止本轮 dev；还原 `src/main/index.ts`，与基分支 diff 为零；6175 无监听；手机无线 shell 仍正常 |

实际重启的服务 PID 为 78530，启动时间 15:45:54。此处验证了真实重启和失败收尾；成功修复编排由替身测试覆盖，真实手机验证了正常连接及 shell。没有自然复现最初的旧进程故障，不将本次实测描述为其底层原因已经确诊。
