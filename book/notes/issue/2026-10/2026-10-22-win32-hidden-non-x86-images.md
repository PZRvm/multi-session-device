# win32 过滤后本地非 x86_64 镜像不可见

- **问题**：P5 的镜像目录按宿主 ABI 过滤（win32 只列 x86_64）后，用户本地 SDK 里若有非 x86_64 镜像（典型：从 mac 机器整目录拷来的 SDK），在 Windows 上不再出现在目录里——占用磁盘但无入口可见，也无法从应用内卸载。
- **复现**：win32 上把含 arm64-v8a 镜像的 SDK 设为活动根 → 向导镜像表只列 x86_64 条目 → arm64 镜像既不展示也无卸载入口。
- **建议方向**：一期接受（plan 2026-10-22-windows-emulator-env 风险 ② 既有决策：场景罕见、x86_64 API 21+ 全覆盖）。后续如需改进：目录装配时统计被过滤的已装条目数，镜像表尾部加一条「另有 N 个本机不可用的已装镜像（非 x86_64）」提示行，点击展开可见列表 + 卸载入口（卸载语义与 ABI 无关，可复用现有 uninstall 链）。
