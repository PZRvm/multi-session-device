# P3：Windows 图标母版外沿仍有少量杂色

- 观察：2026-11-02 黑屏修订的资源复核中，1254px 母版在前层手机底部和后层手机外沿仍可见少量黄、青色杂点。图像生成整理边缘后仍未完全消除；从 Windows EXE 提取的 32px 图标能清楚识别黑屏三手机。
- 复现：以原尺寸查看 `resources/logo-multi-session-device-windows.png`，放大检查前层手机下沿和后层手机右侧。
- 建议方向：后续单独整理母版 alpha 外轮廓，再导出运行时 PNG/ICO。本轮需求是屏幕改黑，资源评审阶段只记录，不继续修改。

后续状态：用户已改选 Codex 直接生成的透明屏幕版，正式母版和导出图已覆盖旧黑屏版本，旧母版不再留在仓库。透明试稿中抽样的红色杂点 alpha 为 1/255，三块屏幕中心 alpha 为 0；本轮遵照用户要求直接采用生成原图，不对这些像素另做后处理。
