# book 相对链接按目录深度算，issue/learn 有月份子目录

同一天两次踩同一个坑：从 book 文档链到 `src/` 的相对路径少写一级，被
`npm run book:index` 的断链校验逮住（第一次 think-report → plans 用了两级，第二次
issue → src 用了三级）。规律：

- `book/plans/*.md`、`book/notes/think-report/*.md`：文件在 book 下**两级**，链 src 用
  `../../src/...`。
- `book/notes/issue/2026-10/*.md`、`book/notes/learn/2026-10/*.md`：月份子目录多一级，
  文件在 book 下**三级**，链 src 要 `../../../../src/...`，链回 book 内其他目录也相应
  多一级。

排查技巧：断链信息只给「来源文件 → 目标」不解释层级，用
`node -e "require('path').resolve(dirname(abs), target)"` 打印实际解析路径一眼看出差几级。
