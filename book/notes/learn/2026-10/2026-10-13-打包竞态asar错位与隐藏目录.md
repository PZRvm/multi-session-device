# 打包竞态：asar 错位闪退与隐藏目录排除

**症状**：`build:mac` 产物装进 /Applications，打开即闪退——无崩溃报告、无 stderr、统一日志空白；启动台也不显示图标。dev 模式完全正常（dev 不走 asar）。

## 真凶：asar 内容区与索引错位

electron-builder 打 asar 是"先扫描全部文件大小建索引，再逐个写内容"。打包期间项目树里任何文件被写入，写出的内容就和索引记录的大小对不上，**其后所有文件的偏移整体漂移**。本次两连击：

1. `.zcode/`（ZCode 会话计划、技能）、`.workbuddy/`（记忆笔记）这些**会话状态隐藏目录**被工具实时写入——62 个文件错位，拖累其后整个 `out/**`。electron-builder 默认把隐藏目录打进包（模板里 `!**/.vscode/*` 这种排除的存在就是证据）。
2. 漂移后 asar 里的 `out/main/index.js` 开头混入了别的文件的尾部字节（第一次是 `e2e/cdp-smoke.mjs` 的尾巴，第二次是某笔记的"无"。）），主进程加载即 `SyntaxError: Invalid or unexpected token`，exit 1。因为死在 JS 加载阶段、crash reporter 又没起来，**错误不落任何日志**——electron-builder 也不校验自己打的 asar，坏包静默出货。

## 诊断手法（沉淀）

- **最小对照**：node_modules 原版 Electron 能跑 → 排除机器环境；`ELECTRON_RUN_AS_NODE=1` 能跑 → 二进制和框架加载没问题；原版 Electron 加载解包后的应用代码能跑 → 业务代码没问题 → 锁定打包产物。
- **asar 直接取证**（零依赖）：头布局 `[4..8)`=头 pickle 长度、`[12..16)`=头 JSON 字节长、内容区起点 `8+头长`、文件偏移相对内容区。按索引逐文件截取窗口与磁盘字节对比，能精确圈出"从哪个文件开始错位"。
- `node --check` asar 里的 `out/main/index.js` 直接复现 SyntaxError。
- 注意陷阱：node_modules 里大量相同 LICENSE/同内容文件会让 `data.find()` 全局搜索撞车，**要局部搜索或干脆全量流式对比**；node_modules 的 package.json 是 electron-builder 裁剪过字段的（去 bugs 等），与磁盘原样不同属正常，对比时要跳过。
- `~/Library/Logs/DiagnosticReports/` 里 VS Code 的 `chrome_crashpad_handler` 连环崩溃日志与本病无关，别被带偏。

## 修复三件套

1. **files 排除**：`!**/.*` + `!**/.*/**` 排除一切隐藏目录（根治竞态源），另排除 `book/ e2e/ scripts/` 等纯仓库内容（asar 从 69MB 瘦下来，中文文件名也不再进包）。
2. **afterPack ad-hoc 签名**（`scripts/adhoc-sign-mac.cjs`）：无证书时 electron-builder 直接跳过签名，产物缺 `_CodeSignature`，macOS 视为损坏（codesign 报 "code has no resources but signature indicates they must be present"）——这是**启动台无图标**的直接原因。注意 `mac.identity: null` 的语义是"跳过签名"（读 node_modules 源码 `MacTargetHelper.handleNullIdentity` 确认），不是 ad-hoc，不能用；正确做法是 afterPack 钩子里 `codesign --force --deep --sign -`。
3. **asar 校验脚本**（`scripts/verify-packaged-asar.mjs`，已接 `build:mac` 末步）：主入口与仓库 out 产物逐字节比对 + `node --check` + package.json 可解析 + 内容区不越界 + 排除项未混入。**第一次跑就抓住了干净重建下的复发**——证明这不是偶发竞态而是"只要会话工具活着就必现"，这类打包产物问题必须在装进 /Applications 前拦下。

## 顺带修正

- `mac.extendInfo` 写成 YAML 列表会生成 `"0"/"1"/"2"/"3"/"length"` 垃圾键，且中文权限描述根本没生效（顶层还是模板英文默认）——extendInfo 必须是映射。
- 启动台图标：装好后 `open` 一次或 `lsregister -f` 即注册；验证用 `lsregister -dump | grep path`，别去找老教程的 `~/Library/Application Support/Dock/*.db`（新系统没有）。
