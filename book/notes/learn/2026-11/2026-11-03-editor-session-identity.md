# 截图来源、图片版本和窗口代次分别管理

- **场景**：同设备多张截图同时编辑，产出后可续编，旧窗不覆盖新图。
- **原因**：设备 ID 无法区分截图；captureId 会随成品更新，不能作为稳定窗口身份。取图时读取设备最近槽还会遇到开窗期间再次截屏的竞态。
- **怎么用**：真实采集生成稳定来源身份，编辑产出更新版本，窗口重开生成新会话 ID。开窗首次 await 前固定图片并登记；sender 只解析 main 内部会话。回写最近缓存以旧条目对象身份作比较。

# 删除登记时同时解除图片引用

- **场景**：窗口关闭或设备停止后，从编辑会话 Map 删除记录。
- **原因**：窗口事件里的 onRelease 闭包仍可能持有会话对象，单纯 delete Map 不保证大图 Buffer 可回收。
- **怎么用**：释放时显式将会话 shot 置 undefined，再删除登记；下载在途保留必要局部引用直到任务结束，完成后检查会话和条目身份，防止回填已清缓存。
