# 模拟器对接（Android） — 总结

- **背景**：从假数据切到真模拟器，顺序即风险顺序：PoC 闸门 → SDK 引导 → 生命周期接真 → 投屏操控产品化。SDK bootstrap 全量在本 stage（bootstrap JRE + cmdline-tools + platform-tools + emulator，镜像向导内按需下载，许可应用内确认，独立 SDK 根）。完成判据：应用内新建一台 AVD 并投屏操控，PoC 验收线达标（≥30fps、触摸延迟 ≤150ms），不过线即停。
- **做了什么**：PoC 闸门过线（host GPU 59fps、触摸中位 75ms）；SDK bootstrap 四件套（JRE 21 + cmdline-tools 23 + platform-tools 37.0.1 + emulator 37.2.12，1.8GB 落独立根）+ 应用内许可确认；新建/删除接真（avdmanager 失效改内置画像 + 手写 config）；emulator runner（子进程池、端口避让、状态机、SIGKILL 回写崩溃）；投屏操控产品化（WebCodecs + canvas 等比居中、触控/滑动/捏合/键盘/物理键，CDP 36-37fps）；持久化对账及其四切片 review（6 项 P2、26 项 P3 全修）；配置安全/摄像头/虚拟场景等后续修复批推进至 10-09（全量 786 通过）。
- **为什么这么选**：顺序即风险顺序：PoC 闸门 → SDK 引导 → 生命周期接真 → 投屏产品化，PoC 不过线即停（概述原文决定）
- **结果**：六步全部完成并于 2026-10-08 关闭（frontmatter status: completed）；PoC host GPU 59fps/触摸中位 75ms 过线，后续修复批推进至 10-09（全量 786 通过）
- **后续**：Quick 门槛、摄像头取景、六类等遗留见 wizard-plan-remaining-acceptance issue；硬件/跨形态延期验收不变
