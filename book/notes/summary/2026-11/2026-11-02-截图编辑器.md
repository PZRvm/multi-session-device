# 截图编辑器

## 背景

截图气泡此前只有「保存」一条产出路径，用户截图后想加标注（矩形/箭头/文字/马赛克/裁剪）必须去外部工具。姊妹仓库 multi-session-browser 已有成熟的截图编辑器（Konva 画布 + 独立编辑窗），计划 [2026-11-02-screenshot-editor](../../../plans/2026-11-02-screenshot-editor.md) 决定以"直接复制源代码 > 必要适配 > 新写"的纪律整体迁入。

## 做了什么

按计划 T1—T8 六阶段推进，五次功能提交（77a2681 / 0149847 / 9e3d3f8 / 845473a / e7bb76d）加一次门禁修复（36becab）：

- **契约与常量（T1）**：`src/shared/screenshot-editor.ts` 契约、`editorConstants`（与源零代码差异，diff 验证非注释行差 0；源注释字号 36/42/50 过时，实际 32/42/54）、三语字典、IPC 四通道、ADR-005、konva@10.8.0 + react-konva@19.2.7。
- **主进程（T2）**：CachedShot 增 captureId（新截图与编辑成品回写都换新 id，旧引用自然过期）；`writeShotToDownloads` 从原 save 链抽取共享（唯一临时名 + link 原子占名 + EEXIST 撞名重试）；编辑四通道 handler——归属由窗口登记表解析（不信 renderer 自报 id），入参全链守卫（PNG data URL 前缀 + 30MB 封顶 + nativeImage 验图）。
- **编辑窗控制器（T3）**：设备单例 Map（一设备一窗，与 settings/logcat 全局单例不同）；窗口尺寸自适应算法迁自来源（锚点常量原值，只缩不放）；15s 超时、崩溃后释放登记可重开；主窗 closed 级联关闭。
- **编辑器组件（T4）**：AnnotationStage / EditorToolbar / EditorWindow / editorWrapper（源 app.css 完整段搬家 + 13 个 token 映射）迁入。接缝共四类，逐项 diff 记录在 plan T4 节：i18n（useCopy 替换）、lucide 图标（含删除源的 glyph-circle 兜底——lucide 有 Circle）、storeCopy/toApiResult 错误链、result.fileName 替代 path+basename。
- **入口接线（T5）**：气泡 copied/saved 态「编辑」钮（失败态无入口）、`useScreenshot.edit()` 独立 busy（editingRef 防重）、DeviceCanvas / ExternalCanvas 双画布透传。
- **门禁与评审**：lint 修复 1 error + 51 prettier warning；八项评审清单过完整 diff，无 P1/P2，1 项 P3 记录在案。

## 为什么这么选

复用优先于新写：编辑器画布（历史栈、双马赛克、裁剪、IME 文本）是约 1800 行成熟逻辑，重写必然引入行为漂移。所有与源的执行逻辑差异都做成显式接缝并逐条记录理由（plan T4 节），包括两处主动收敛：darwin 窗体 chrome 用本项目三灯度量（窗口形态单源回正）、sandbox 沿本项目 true（源 false 是其仓库先例）。产出语义保留来源行为：导出后成品作新底图、清空标注与历史（「单槽 = 最近一次成品」契约），复制→下载经 rebaseAfterExport 换新 captureId 不误报过期。

## 结果

- 自动门禁：typecheck / lint / build 绿；本功能 91 用例全绿（screenshot 34 仅 1 条 `/bin/sleep` 基线失败，`git show 3af2256` 确认基线固有）；全量其余 154 失败均为基线 Windows 平台问题（[基线 issue](../../issue/2026-11/2026-11-02-windows-test-baseline.md) 已有记录），`git diff 3af2256..HEAD -- src/main/devices/` 为空佐证与本功能无关。
- 人工验收：用户在真实画布逐组操作 V1—V9（形状/画笔、双马赛克、IME 文字、裁剪、历史、复制下载、双设备入口与隔离、主题三语、窗口重开），全部通过；证据记录见 [POC](../../../docs/poc/2026-11-02-screenshot-editor.md)。
- 评审：[P3 一项](../../issue/2026-11/2026-11-02-screenshot-editor-review.md)（导出防重 React state 理论重入窗口，来源同款，main 侧占位兜底）。
- 未验边界：macOS Retina 无可用环境未实测；验收当日真机 RF8XA011VNA 后期离线，V7 以网络设备 + 此前双设备在场时的行为为准。
