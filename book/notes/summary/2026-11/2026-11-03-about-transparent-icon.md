# 关于页使用透明图标

关于页原先仅在 Windows 使用去背景的三手机图标，其余平台仍显示带底板版本。用户要求复用 resources 中已有的透明版本。

`PaneAbout.tsx` 现统一引用 `resources/icon-windows.png`，保持 64×64 尺寸。复用已完成的资源即可满足需求，无需重新出图；系统、Dock、窗口和安装包图标不变。
