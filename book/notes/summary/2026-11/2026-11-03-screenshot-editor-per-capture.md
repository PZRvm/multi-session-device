# 新截图打开独立编辑窗口

截第一张图并打开编辑页，再截第二张点编辑，原先只会聚焦第一张窗口。窗口以设备 ID 为单例，图片又共用每设备最近槽；即便只改开窗逻辑，旧图也会因版本对账过期而无法导出。

现在每次真实截图保留稳定来源身份，编辑会话固定当时图片，窗口按会话登记。同一张反复点编辑仍聚焦原窗；新的截图开新窗，各自保留标注、复制、下载和续编。成品更新本窗版本，只有仍对应设备最近条目时才回写最近缓存，旧窗口不会覆盖新截图。

继续使用现有 IPC 载荷和 renderer 续编流程，画布、布局和 ADB 采集不改。设备停止使其全部编辑会话失效；关窗、加载失败、崩溃和清理都释放快照引用，迟到回调不能删除新会话。下载已发布文件如实成功，已关窗或失效的数据不回填。

先用失败测试复现旧窗导出过期，再验证多窗、同图复用、开窗期间新截图、下载期间新截图或关窗、跨窗伪造版本、空页及停止重启。全仓 1568 项通过、6 项跳过；build（含 typecheck）、lint、格式和 diff 空白检查通过。

真实 Electron 39.8.10 使用两张合成 PNG 跑真实截图 IPC、preload、窗口及构建后的编辑页面：第一窗画矩形，第二张开新窗，首窗标注仍可撤销，两图分别显示；首窗页面复制与下载可续编，原保存仍为第二图；停止后旧会话拒绝取图。证据目录为 `/var/folders/r8/m81f7g6102x8s3fg8fjrpbv00000gn/T/msd-editor-real-1kwoT9/`，包含两窗 PNG 与 result.json。本轮没有连接真机重验 ADB 采集。
