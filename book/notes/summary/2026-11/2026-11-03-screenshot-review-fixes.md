# 图片编辑复审问题修复

复审发现，图片编辑工具栏使用 CSS 像素上报高度，而原生三灯位置使用窗口 DIP；页面缩放后两者不再共线。开发配置还会在判断显式端口覆盖前读取本地元数据，坏 JSON 或 null 会阻断开发与构建。用户授权修复两项问题，本轮在 dev 实施。

窗口控制器现以本窗 getZoomFactor 转换高度，再定位原生按钮；来源限制仍为本窗主 frame，最小高度校验容纳亚像素误差。renderer 保留宽度变化触发的上报，覆盖宽窗中工具栏高度不变的缩放。

开发配置改为按 command 延迟选择端口：有效 MSD_DEV_PORT 优先，其次为有效元数据端口，否则使用 6174。端口必须是 1–65535 的整数，读取和 JSON 解析异常会回退；build 不读取调试元数据。这让可选本地文件不会阻断显式配置或生产构建。

先补回归测试，复现 14 项失败断言后实施修复。新增 20 项端口边界测试及 1 项缩放定位测试。真实 Electron 加载构建后的编辑器和实际窗口控制器，720px / 1280px 下执行 100% → 125% → 80% → 110% → 100%，共 10 场景最大中心差约 0.45 DIP。真实 electron-vite 配置加载覆盖正常、坏 JSON、null 与显式覆盖，serve/build 共 6 场景通过。全仓 1560 项通过、6 项跳过；build（含 typecheck）、lint、格式检查通过。

按八项 review checklist 复核，未发现新增阻塞问题。两项[复审问题](../../issue/2026-11/2026-11-03-screenshot-layout-review.md)已补充修复结果；施工图见[计划](../../../plans/2026-11-03-screenshot-review-fixes.md)。主进程改动需要重启开发进程后加载。
