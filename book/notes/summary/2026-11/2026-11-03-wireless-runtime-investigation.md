# 三星手机转无线失败排查

用户已插着手机，点击「转为无线」反复收到确认 Wi-Fi 的提示。本次范围为当前手机、共享 ADB 服务及无线连接链路的运行态排查；不改连接协议、持久化或其他功能代码。

USB 识别为三星 SM-A155F / Android 14。手机 Wi-Fi 地址 `192.168.31.162`，电脑 `192.168.31.134`；手机监听 5555，能 ping 通电脑，电脑 `nc` 也能连接手机端口。应用和命令行 ADB 均连接失败，原始错误为 `No route to host`。

macOS 日志确认旧共享 ADB 服务被 `Local network prohibited` 拦截，权限归属指向 Warp。设置页开关显示开启仍不足以说明该进程可访问；系统归档存在同 bundle id 的不同记录，但没有证明重复记录就是触发原因。

手工重启一次共享 ADB 服务后，连接立即成功。选择运行态恢复，是因为手机地址、监听与网络路径都正常，且已有明确的系统拒绝日志；无需修改应用代码或代理设置。

验证结果：

- `adb connect 192.168.31.162:5555` 返回 `connected to 192.168.31.162:5555`。
- `adb devices -l` 中无线 transport 为 `device`。
- 无线 shell 返回 `SM-A155F` 和 `14`。
- 正在运行的 `/Applications/多开模拟器.app` 显示 Wi-Fi 接入及 `192.168.31.162:5555 · 已连接`。

本次没有修改应用源码，未运行代码测试；没有新建实现 plan，也没有关闭原无线计划中尚未执行的其他硬件验收。拔线后的持续投屏尚未验证。排查过程和复用方法见 [经验](../../learn/2026-11/2026-11-03-adb-local-network-prohibited.md)，提示遗漏电脑端原因的问题见 [issue](../../issue/2026-11/2026-11-03-wireless-unreachable-diagnostics.md)。
