# 1.0.1 已发布

用户要求当前 dev 合并 main、版本更新到1.0.1，并说明更新内容。本次发布包括投屏静置首帧与连续恢复修复、设备拖拽排序、macOS host GPU 模拟器休眠恢复、无线连接诊断和用户确认修复、截图会话隔离及操作提示改进。完整说明在[Release](https://github.com/PZRvm/multi-session-device/releases/tag/v1.0.1)。

版本提交 `a1d901c` 同步 package 与 lock，并更新发布模板。[PR #2](https://github.com/PZRvm/multi-session-device/pull/2) 六项检查通过后，以 `326a623260fd76d98daf85fa6e00aa9da5311e3c` 合并 main，保留同仓库 dev→main merged-PR 发布机制。用户授权涵盖本轮推送、合并和发布，未直推 main，未覆盖 v1.0.0。

本地1701项测试通过、8项原有条件跳过；typecheck、lint和book检查通过。main推送检查及[发布流水线](https://github.com/PZRvm/multi-session-device/actions/runs/42766788246)全部成功，macOS ARM64 DMG、Windows x64 EXE和SHA256SUMS均已发布。标签和Release target等于merge SHA；下载SHA256SUMS后与GitHub提供的两个附件digest及校验文件自身digest逐项匹配。

预览版、签名和平台验收边界沿用发布说明。未在本机重新下载两份完整安装包，现场投屏体验与模拟器残留仍按[已有问题](../../issue/2026-11/2026-11-10-screen-runtime-followups.md)跟踪。发布记录提交dev，本地main保持发布提交。
