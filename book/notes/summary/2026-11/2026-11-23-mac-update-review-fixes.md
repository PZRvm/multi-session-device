# Mac 更新退出与换版回归

取消普通退出后，下一次更新周期重新核对退出许可。点击下载时固定候选版本。重查发现版本变化会结束旧请求，显示新候选和版本说明，并等待用户的新操作。

Apple Silicon 上用三个独立测试包和临时 Ed25519 密钥验证。第一次退出在 Sparkle 完成取消后被测试监听器拦回。重新下载并选择稍后，再退出时测试应用仍为 `90.0.1`。旧归档 `90.0.2` 返回 HTTP 503 后，更新源切到 `90.0.3`，重试只刷新候选。再次选择下载并确认重启后，测试应用替换为 `90.0.3` 并重新打开，隔离数据保留。
