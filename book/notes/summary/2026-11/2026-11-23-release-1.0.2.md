# 1.0.2 稳定版发布总结

- `1.0.2` 是首个启用应用内更新的正式版。Apple Silicon 下载 DMG，Windows x64 下载 NSIS EXE。从 `1.0.1` 或更早版本升级时先手动安装一次，后续可在「设置 → 关于」检查稳定版更新。[正式版](https://github.com/PZRvm/multi-session-device/releases/tag/v1.0.2)
- Mac 前一轮用临时密钥覆盖了取消后退出与下载失败后换版。Windows Server 2022 runner 真正安装了隔离版 `90.0.1`，确认后才更新、重启到 `90.0.2` 并保留数据标记。[应用内更新计划](../../../plans/2026-11-23-in-app-update.md) · [Windows 回归](https://github.com/PZRvm/multi-session-device/actions/runs/45158123232)
- 首发工作流的一次 Mac 日志测试失败后重跑通过。两平台产物和正式 Mac 签名齐备，草稿查询 404 阻断公开。用同一流水线产物复核原草稿的合并 SHA、说明和全部 8 个附件后继续发布，修正后的脚本会查询唯一草稿并阻止重复创建。[发布流水线](https://github.com/PZRvm/multi-session-device/actions/runs/45158838866) · [修复 PR](https://github.com/PZRvm/multi-session-device/pull/4)
- 发布后核对 GitHub Latest、Tag、七项校验值和两份公开更新清单。专用设备的录屏、投屏及共享 SDK 升级场景仍待实机验收。正式渠道从 `1.0.2` 升到下一版的安装链路可在下一版发布时验证。[发布计划](../../../plans/2026-11-23-release-1.0.2.md)
