## Requirements brief（Step 0）

**背景**：stage 04 模拟器对接需要一个 UI 容器。本阶段交付纯前端会话管理壳：左右分栏 + 设备列表全量交互，状态与数据走主进程 JSON 元数据（重启保留），模拟器本体零接触。

**范围（影响什么）**：

- `src/shared/`：Device/DeviceStatus/CreateDeviceInput 类型 + devices:* 通道名（契约单源）
- `src/main/`：`store.ts`（元数据落盘唯一写入口，单文件原子写）+ `devices/`（注册表 + IPC handler + changed 广播）
- `src/preload/`：`window.api.devices` 白名单（含 onChanged 订阅）
- `src/renderer/`：deviceStore 镜像 store；组件 ResizeHandle / DeviceRow / DeviceListPane / CanvasPlaceholder / DeviceWizard；App.tsx 重写为分栏壳；删除 demo 用 appStore
- `book/stage/03`：四步（步骤 4 已批转正）勾选回写

**排除项（明确不影响）**：

- 不接 Android：无 sdk/avd/emulator/scrcpy 任何调用（stage 04）
- 不做设置窗与主题色切换 UI（stage 05）——壳内不再有亮暗切换入口，外观走「跟随系统」；自检壳 demo（计数、dialog 演示按钮）随 App 重写移除，五件基线组件与其测试只复用不改动
- 不做拖拽排序与右键菜单（PRD A 的完整交互，stage 步骤未列；列表顺序 = 创建顺序，删除触发行内悬停删除按钮）——记 deferred
- 不做运行中 serial 显示/复制、启动中态与取消（无真实运行；mock 状态机仅 停止⇄运行中 直切）
- 主进程建窗背景接入顺延 stage 05（用户拍板）；不新增依赖

**边界**：面板宽 220–420px、初始 280px；重命名拒绝空/纯空白，上限 50 字符，Enter 提交 Esc 取消；删除必经主进程 dialog 确认，后果列明「AVD 目录将被永久删除」；status 为运行态不入盘，重启一律回到「停止」。

**learn/ 检索**：`2026-10-03-vitest-testing-library-gotchas`（RTL cleanup + useState Harness）直接适用；`2026-10-01-dialog-unhandled-rejection`（toApiResult 包装）直接适用；`2026-10-03-cdp-smoke-no-test-framework` + `2026-10-03-electron-enable-logging` 用于冒烟；`2026-10-03-segmented-roving-focus`（radiogroup 焦点搬运惯例）供向导单选列表参考。

## Design（Phase 2）

**数据流**（主进程事实源，renderer 镜像 + 命令——architecture 边界不变量）：

```
renderer                      preload                  main
DeviceWizard/DeviceRow  →  window.api.devices.*  →  devices/index.ts（守卫→变更→落盘→广播 changed→返回新列表）
deviceStore（zustand 镜像） ←  onChanged 推送 / handler 返回值
```

- 落盘：`userData/devices.json`，`{ version: 1, devices: DeviceMeta[] }`；写 = tmp 文件 + rename 原子替换；读失败按空表起步（不静默改写原文件）。持久化字段 = id/name/profileId/profileLabel/apiLevel/variant/createdAt；status 只在主进程内存。
- id：`crypto.randomUUID()`（main 生成）。

**接口**：

- 通道：`devices:list` / `devices:create` / `devices:rename` / `devices:delete` / `devices:set-running` / `devices:changed`（推送 Device[]）。
- main handler 全部先过运行时守卫（payload 不可信）：name trim 后非空且 ≤50、apiLevel 为整数、variant ∈ aosp|google_apis|google_play；非法直接抛错（invoke reject）。
- preload：`list/create/rename/remove/setRunning/onChanged(cb)→unsubscribe`。
- deviceStore：`{ devices, selectedId, loaded, load(), create(), rename(), remove(), setRunning(), setSelected(), applyDevices() }`；selected 失效时回落到相邻/首台。

**组件与视觉**：

- 壳：flex 行布局 100vh；左栏定宽（state），ResizeHandle 5px 命中区、中缝 1px `--panel-divider`，role="separator" + 左右方向键 ±16px；右栏 CanvasPlaceholder（board-bg 工作台，居中提示，stage 04 接投屏）。
- DeviceRow：div 栅格复刻 ListRow 视觉（选中 = 整行反白 aria-current）；状态点 running=`--loading`、stopped=`--idle`；副行「画像 · API x · 状态」；行尾 Play/Square 启停钮 + 悬停 Trash2 删除钮；双击标题进行内重命名。
- DeviceWizard：右栏内容替换（非模态）。三步 画像→镜像→命名，MOCK 数据（Pixel 8/8 Pro/6a/Tablet × API 33–35 三变体）；radiogroup 语义；名称默认「画像名 API 版本」；创建 → store.create → 关向导并选中新设备。
