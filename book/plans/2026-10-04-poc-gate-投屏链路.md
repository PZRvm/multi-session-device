# PoC 闸门：投屏与触控最小链路 — plan

> 批准记录：2026-10-04 用户下令「为 stage04 执行前三个步骤并且编写开发计划，执行完毕之后我确认一遍计划」（bocode-boscope：明确下令实现算批准；计划事后由用户复核）。分支 `feature/stage04-emulator-integration`（自 dev 切出）。stage 顺序即风险顺序：本 PoC 是闸门，不过验收线即停，后续 SDK bootstrap 与 AVD 接真两步不再执行。

## Requirements brief（Step 0）

**背景**：stage 04 的全部后续（bootstrap、接真、投屏产品化）押在一条画面链路上：主进程 Tango（@yume-chan/adb）连本机 adb server → 推 scrcpy-server 到 AVD → H.264 流经 IPC 送 renderer → WebCodecs 硬解 → canvas 渲染；触控反向经 scrcpy 控制协议注入。PRD 成功标准第 1 条要求这条链路实测达标：**交互场景帧率 ≥30fps，触摸端到端延迟 ≤150ms**。本 PoC 在本机已有 SDK（`~/Library/Android/sdk`）前提下跑通最小链路并出数。

**范围（影响什么）**：

- 新增依赖（`dependencies`，PRD 4.1 已定的技术选型）：`@yume-chan/adb`、`@yume-chan/adb-scrcpy`、`@yume-chan/scrcpy`、`@yume-chan/scrcpy-decoder-webcodecs`（v2 稳定线：2.6.4 / 2.3.2 / 2.3.0 / 2.5.3）
- `src/renderer/poc.html` + `src/renderer/src/poc/`：PoC 页（第三 HTML 入口，量帧率/延迟的操作台 + canvas + 指标显示）
- `src/main/poc/`：PoC 主进程 harness（建 AVD / 无头启动 / 取流 / 注入），仅 `MSD_POC=1` 时装配
- `src/shared/`：`poc:*` 通道名与 PoC 页消息类型
- `book/docs/poc/`：实测报告（新目录，gen-book-index 目录表补一行）
- `book/stage/04` 步骤 1 勾选回写

**排除项（明确不影响）**：

- 不动产品行为：主窗、向导、设备域零改动（PoC 窗替代主窗仅在 `MSD_POC=1` dev 环境出现）
- 不做产品化投屏：DeviceCanvas、解码复用策略（后台停解码）、捏合/键盘/物理键注入全部属步骤 5——PoC 只验取流 + 单指 swipe/tap
- 不做 SDK bootstrap（步骤 2）：PoC 直接用本机已有 SDK，SDK 根经 `MSD_POC_SDK_ROOT` 指定，默认 `~/Library/Android/sdk`
- 不做子进程池与端口避让（步骤 4）：单实例、固定 `-port 5554`，被占用即报错
- scrcpy-server 随包分发与完整性校验属步骤 5——PoC 运行时从 GitHub release 下载锁定版本到 `userData/poc/` 缓存，报告记录其 sha256
- PoC 页不走设计规范与 impeccable（dev 工具页，非用户界面）

**边界**：验收线只在下述测量法下判定——帧率 = 解码输出帧数 ÷ 计量窗口；触摸延迟 = 注入指令发出（renderer `performance.now()`）到 canvas 像素首变的间隔，取 20 次 swipe 的中位数与 P95。两类 GPU 配置（`-gpu host` 与 `-gpu swiftshader_indirect`）各测一轮；达标判定用 `host`（产品默认），`swiftshader_indirect` 仅记录作降级参考。

**learn/ 检索**：`2026-10-03-cdp-smoke-no-test-framework` + `2026-10-03-electron-enable-logging-renderer-console`（dev 验证手段）；`2026-10-04-electron-vite-multi-page-wizard-window`（加第三个 HTML 入口的三件套）；`2026-10-01-dialog-unhandled-rejection`（toApiResult 惯例）。

**风险**：

- @yume-chan 包为 ESM-only，main 侧若被 electron-vite 默认 externalize 成 `require` 会在运行时炸——实现时把它们排除出 externalize 列表打进 bundle，typecheck + 真机跑通为准
- scrcpy 协议与 server 版本耦合：server 版本锁定为 @yume-chan/scrcpy 2.3.0 支持的最高稳定版（安装后从包导出确认），报告记录版本对
- 本机 adb server（homebrew adb 36.0.2）可能已被其他客户端占用：共享 5037 是产品语义，PoC 沿用，只读不动
- 像素首变判延迟可能被系统动画噪声污染：设备侧关动画（`window_animation_scale 0` 等三键），判定阈值用降采样 ROI 的平均差而不是单点

## Design（Phase 2）

**数据流**（流生命周期 ≠ 解码渲染，architecture 边界不变量——主进程只编排，解码渲染只在 renderer）：

```
main/poc                                renderer/poc
────────                                ────────────
avdmanager create avd（ANDROID_AVD_HOME 隔离到 userData/poc/avd-home）
emulator @mst_poc -no-window -no-audio -no-boot-anim -gpu <mode> -port 5554
adb 轮询 sys.boot_completed（spawn 本机 platform-tools adb）
Tango AdbServerClient（node net 连 127.0.0.1:5037）
  → push scrcpy-server → 打开 video+control
video 流 ── MessagePort ──────────────→ WebCodecs 解码 → canvas 绘制（rAF 逐帧）
poc:inject（tap/swipe 坐标）←── IPC ───  操作台按钮/脚本驱动
                                        计量：解码计数 fps；像素首变延迟 → poc:report
```

**接口**：

- 通道：`poc:setup`（建 AVD，已存在则跳过）、`poc:emulator-start`（`mode: 'host' | 'swiftshader_indirect'`）、`poc:emulator-stop`、`poc:stream-start`（renderer 发 MessagePort 过来）、`poc:inject`（`tap | swipe` + 归一化坐标）、`poc:teardown`（停模拟器 + 删 PoC AVD 目录）、`poc:report`（指标 JSON 落 `userData/poc/report-<ts>.json`）、`poc:log`（主进程状态行推送）。
- main 侧 handler 先过守卫（PoC 页同为不可信 sender）；`poc:*` 全部只在 dev 且 `MSD_POC=1` 时注册。
- scrcpy-server：GitHub release 固定 URL 下载（版本对记录在报告），缓存 `userData/poc/scrcpy-server`。
- 计量协议：操作台「跑一轮」按钮依次执行 warmup 5s → 静置计帧 10s → 连续 swipe 计帧 10s（每 600ms 一次，滑开/收起抽屉交替）→ 延迟 20 连发 swipe（700ms 间隔，逐发等像素首变或 2s 超时）→ 汇总 JSON。延迟单发流程：降采样 ROI（160×320 中心区）基线快照 → 发 `poc:inject` → rAF 循环里逐帧比对，平均差 >6/255 记首变时间。

**AVD 与环境**：

- AVD：`avdmanager create avd -n mst_poc -k "system-images;android-36;google_apis;arm64-v8a" -d pixel_8`（stdin 喂 `no` 避开自定义硬件画像问句），env 隔离三件：`ANDROID_AVD_HOME=<userData>/poc/avd-home`、`ANDROID_USER_HOME=<userData>/poc/android-user`、`JAVA_HOME` 用本机 JDK 17（`/usr/libexec/java_home -v 17` 探测）。
- 启动前 `adb start-server`；启动参数固定 `-port 5554`，占用即失败并报明。
- 设备侧关动画：`settings put global window_animation_scale 0`（+ transition/ animator 两个同键）。

## Build order

1. 依赖接入 + vite 第三入口 + `poc:*` 通道/类型——验证：typecheck 绿、`MSD_POC=1 npm run dev` 能开 PoC 空页
2. main harness：建 AVD + 无头启动 + boot 轮询 + `poc:log` 推送——验证：本机真跑，`adb devices` 见 `emulator-5554`，PoC 页看到 boot 日志
3. 取流：Tango 连接 + push scrcpy-server + MessagePort 送流 + renderer WebCodecs 解码上 canvas——验证：页面出画面
4. 注入：`poc:inject` 转控制协议消息——验证：页面出画面后点「滑动」，画面跟着动
5. 计量：fps 计数 + 像素首变延迟 + `poc:report` 落盘——验证：报告 JSON 产出且字段齐
6. 两轮 GPU 配置实测 → 撰写 `book/docs/poc/` 报告 → 对照验收线判过/停
7. Phase 5 review 只记录 → Phase 6 回写（stage 勾选、learn、plan 翻 completed、book:index）
