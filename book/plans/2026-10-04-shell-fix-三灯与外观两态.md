# 壳修复：设备文案 + 失焦三灯 + 外观两态 — plan

> 批准记录：2026-10-04 用户三条修复令（「会话改设备；失焦时左上角按钮被隐藏；点切换出图 1 菜单、拖宽出图 2 三段」），明确下令即批准。

## Requirements brief（Step 0）

**背景**：板头优化轮的三条体验修复。

**范围**：`main/window/index.ts`（三灯可见性治理）；`components/BoardHead.tsx`（文案 + 外观入口两态 + 弹出菜单/分段组）；`App.tsx`（传 panelWidth）；BoardHead 测试重写。

**排除项**：不动设备数据流、向导窗、SegmentedControl 基线组件（图标版分段在 BoardHead 内联实现）；非 darwin 平台不涉三灯；不引入 antd/依赖。

**边界**：宽度阈值 390（姊妹仓库 AppearanceEntry 定稿值，[390,420] 可达区间内有解）；菜单点击外部/Esc 关闭；文案 跟随系统/白天/黑夜（用户措辞替代原 亮/暗）。

**复现结论（Phase 1）**：失焦隐藏的是 **macOS 原生三灯**（聚焦红黄绿、失焦整组消失），页面内板头钮不消失——`titleBarStyle: 'hidden'` 的已知怪癖；姊妹仓库同款治理 = macOS 专有 `setWindowButtonVisibility`（shell.ts 先例）。

## Design（Phase 2）

1. **三灯**：主窗 blur/focus/ready-to-show 三处强制 `setWindowButtonVisibility(true)`（darwin 门控）。冒烟实测失效则退级 `titleBarStyle: 'hiddenInset'`。
2. **文案**：计数标签 会话→设备（aria-label 连动）。
3. **外观入口两态**（阈值 390）：
   - 窄：单图标钮（当前态图标）→ 点击弹菜单（图 1）：三行 Monitor/跟随系统、Sun/白天、Moon/黑夜，当前行高亮（menuitemradio aria-checked）；点选即换且收起；外部点击/Esc 收起。
   - 宽：三段分段组（图 2）：描边容器 + 三图标钮，选中瓣 segment-selected 底 + tile-ink 字；radiogroup 语义，点选即换。

## Build order

1. main 三灯治理 → typecheck:node 绿
2. BoardHead 两态 + 菜单 + 文案 + App 传宽 → 测试重写全绿
3. 静态三关
4. 冒烟：失焦截屏（三灯仍在）、菜单展开截屏、拖宽三段截屏
5. 回写 + 合回 dev

## Test plan

BoardHead 重写：设备计数补零；窄态菜单展开/选择/aria-checked；宽态分段选中切换；设置钮禁用回归；平台分支回归。冒烟：真实失焦截屏对比。

## Done criteria

三条修复全部生效且冒烟截屏存证；40+ 测试全绿；静态三关绿；stage/03 追加记录、plan 翻 completed、索引重刷、合回 dev。

> 完成记录（2026-10-04）：三条全部落地。① 计数文案 会话→设备（aria-label 连动）；② 三灯失焦消失：`setWindowButtonVisibility(true)` 于 blur 实测抢不过系统 → 改 `titleBarStyle: 'hiddenInset'`（trafficLightPosition 照常生效），真实截屏验证聚焦红黄绿/失焦置灰不消失（CDP 截屏拿不到系统绘制的灯，验证方法记 learn）；③ 外观入口两态：窄 <390 图标钮 + 弹出菜单（跟随系统/白天/黑夜，当前行高亮，外部点击/Esc 收起），宽 ≥390 三段分段（阈值同姊妹仓库 AppearanceEntry 定稿值），CDP 验证菜单选择切黑夜、分段切白天、color-scheme 同步、控制台零错误。45/45 测试绿（BoardHead 重写 10 条）。备注：BoardHead 分段组未做方向键 roving（Tab 可达各钮），与基线 SegmentedControl 的键盘一致性留可用性打磨轮。
