# 设置窗口静态前端 — plan

静态前端子批已完成。用户选择「先做静态布局，交互后续细化」「沿用现有设计系统直接实现」，并于 2026-10-09 认可界面布局；布局示意保留 ASCII 线框。Phase 3 实现与 Phase 4 验证已完成，Phase 5 发现一项 P2 并按 workflow 登记，review 结论为 fix。设置窗完整功能步骤保持未完成。

依据：[PRD](../docs/PRD.md) §2.3 E/G、§1 第 8 条、[stage05](../notes/summary/2026-10/2026-10-16-功能完善.md)、[SDK 来源调研](../notes/think-report/20261009022552-SDK共享检测与真机投屏.md) §2/5、[DESIGN.md](../../DESIGN.md)。

## Requirements brief — Step 0

### Background

移动端测试人员需要集中调整应用外观、界面语言和模拟器环境。现有主窗有禁用的设置齿轮，主题持久化与跨窗同步已存在，设置界面尚未实现。先确定版面，后续再连接配置与业务操作。

### Scope

- Affects：设置窗独立窗口的前端布局、通用/模拟器/快捷键/关于/危险区五个版面、静态展示模型、三语版面文案与前端实施文件清单。
- Does NOT affect：静态实现不写偏好、不切换 SDK、不扫描 Studio、不启停设备、不执行删除、不改变主窗投屏与向导。
- Boundaries：静态阶段只允许分类切换、内容滚动和设计样例切换；业务控件只展示。路径、版本与内存阈值缺数据时留空或显示不可用，样例数据仅用于设计预览，不冒充实际检测结果。

### Requirement

| 版面   | 必须出现的内容                                           | 静态阶段的边界                                       |
| ------ | -------------------------------------------------------- | ---------------------------------------------------- |
| 通用   | 外观三态、琥珀/雾蓝/苔绿三主题色、简体中文/繁体中文/英文 | 展示选中态与控件；不调用主题或语言写入接口           |
| 模拟器 | SDK 来源三态、路径、并行实例上限、内存水位阈值           | 展示选择器、目录行与资源控件；不检测、不核验、不保存 |
| 快捷键 | 当前项目已有操作与键帽排版                               | 只读清单，不提供改键，不搬入浏览器专用操作           |
| 关于   | 应用图标、名称、版本区域、应用数据目录入口               | 正式名称仍 TBD；动态信息留占位，打开目录按钮禁用     |
| 危险区 | 删除本工具创建的全部设备、后果说明、两步确认说明         | 删除入口禁用；确认流程与执行状态留到交互阶段         |

设计轴：

- [recommended — confirm or reject] 沿用主窗/向导的独立非模态窗口与原生三灯；不设置 `parent`，避免跟随主窗移动与固定压层。
- [recommended — confirm or reject] 静态业务控件有完整标签与选中态，禁用写动作；页面标题旁用设计预览标记说明稿件状态，正式交付时不显示开发说明。
- [recommended — confirm or reject] 语言样例采用三语同键字典；正式的语言持久化、跨窗同步和全应用迁移单独推进。
- [recommended — confirm or reject] SDK 与资源约束仅定义版面；运行环境解析、阈值规则与保存策略沿后续对应任务细化。

## Design — Phase 2

ASCII 线框表达信息层级与控件位置；尺寸、间距、颜色、字体和图标以本节说明、`DESIGN.md` 与现有 tokens 为准。路径与动态值仅为展示示例。控件均为静态展示，`x` 表示选中，`v` 表示下拉；三语与 SDK 来源样例随版面一起列出。

### 1. 窗口与信息结构

采用 Operate 模式：测试人员打开设置时直接扫读分类与配置项。视觉权威为本仓库现有 tokens 和界面；姊妹仓库只提供设置结构参考。

建议窗口初始 **760×560 DIP**，最小 **640×460 DIP**，可调整尺寸。相较姊妹仓库 700×480 的起始窗，给 SDK 来源说明与路径更多纵向空间。

- 顶部 40px 拖拽带，标题「设置」水平居中；原生三灯位置沿用本仓库 `{ x: 14, y: 12 }`，左侧留 60px 安全区。
- 左侧 176px 分类栏，右缘 1px 发丝线；通用 → 模拟器 → 快捷键 → 关于固定顺序，危险区沉底。
- 右侧详情区独立滚动，`min-width: 0`，内容内距 14px；导航和窗头固定。
- 普通导航选中整行强调色反白；行本身直角，保持本仓库规则。危险区使用明确的危险文字与图标，危险色接入 token 后再启用颜色。
- 行标签 13px、说明 12px、版面标题 15px/600；数字与键帽用 mono。输入 28px、按钮 32px、行最小 52px；不加卡片、阴影和装饰渐变。
- 一期为桌面窗，不新增移动端版式。640px 窗宽下保留侧栏；说明先折行，必要时标签与控件改上下排，避免横向滚动。

### 3. 前端展示契约与数据流

分类 id 闭集：`general | emulator | shortcuts | about | danger`。分类状态为窗口内瞬态，不落盘。

建议用普通 props 传只读展示模型，放在 `components/settings/model.ts`，暂不进入三进程契约：

```ts
type SettingsPaneId = 'general' | 'emulator' | 'shortcuts' | 'about' | 'danger'
type SettingsLocale = 'zh-CN' | 'zh-TW' | 'en-US'
type SdkMode = 'managed' | 'shared-studio' | 'custom'

interface SettingsViewModel {
  appearance: { mode: ThemeMode; systemId: ThemeSystemId }
  locale: SettingsLocale
  sdk: { mode: SdkMode; path: string | null; detection: 'not-checked' }
  resources: { maxInstances: number; memoryThresholdLabel: string | null }
  about: { appName: string; appVersion: string | null; dataDirectory: string | null }
}
```

`ThemeMode/ThemeSystemId` 复用 shared 既有类型。展示模型不含保存、删除、下载等 callback；三语文案放在设置组件专用字典，同键闭集与语言注册表保证三个版本结构一致。以后全应用 i18n 接入时再统一提升至 `src/shared/i18n/`，不得保留两份运行期事实源。

未来静态实现的数据流：主题 Provider 从现有主题镜像读取板面外观 → `SettingsWindow` 持当前分类 → 当前 Pane 消费只读模型与三语文案。导航只更新 pane；业务字段不更新主进程、不使用 localStorage。预览样例显式命名为 preview，不进入持久化、设备或 SDK 数据。

### 4. 最小窗口接口、权限与通知

独立窗是前端的必要载体；后续静态阶段允许的 main/preload 改动仅限建窗与关窗。

| 提议接口                                     | 返回与守卫                                                                             |
| -------------------------------------------- | -------------------------------------------------------------------------------------- |
| `window.api.settings.open(): Promise<void>`  | 仅登记主窗可调用；加载中复用同一 Promise，就绪重复请求聚焦；就绪前加载失败释放单例引用 |
| `window.api.settings.close(): Promise<void>` | 仅登记设置窗可关闭自身；不接受任意 window id                                           |

通道常量建议为 `settingsOpen/settingsClose`，字面量仅放 `src/shared/ipc-channels.ts`。窗口加载沿用 dev `/settings.html` / prod `loadFile` 分支与现有 15 秒超时模式，`show: false`，ready 后 show。主窗 closed 时显式关闭设置窗；不设置 parent，不使用 modal。

- 权限：`sandbox: true`，沿用 preload 白名单；零 Node/Electron renderer 直访，无文件、网络、摄像头新权限。设置窗不获得设备管理或 SDK 写入权限。
- 通知：静态导航不弹通知。开窗失败由主窗经 `toApiResult` 捕获并使用既有原生 dialog 提示；不引入系统 Notification。
- 两步确认：现有 `dialog:show` 只支持消息/按钮，无法输入确认词；后续需按 PRD 与主进程 dialog 规则明确第二步输入契约，本批不新增自绘确认弹层。
