# 设置窗窗口控件与外观调整

## Step 0：需求

用户参考图明确本批范围：通用分类使用齿轮图标，设置窗顶部标题栏隐藏，红绿窗口控件位于左上角且只保留关闭与全屏；外观使用显示器、太阳、月亮三段，主题色使用方块与选中勾。仍为静态设置，不写偏好，不接语言切换、SDK、资源或删除。主窗外观 tab 已由上一批移除，本批不改主窗。

## Phase 1：分析

现有设置窗有 40px 全宽标题行、Settings2 调节图标及带文字的外观/主题按钮。参考图按 2 倍像素读取：侧栏约 176 DIP，顶部为侧栏窗口控件空间，正文从约 38 DIP 开始；导航有侧边留白与小圆角。保留既有三主题、五分类和详情独立滚动。

Electron 的公开窗口按钮 API 控制整组三灯，不能单独隐藏最小化。使用隐藏标题样式并隐藏原生按钮，renderer 绘制两个可访问按钮；关闭复用原桥，全屏增加仅设置窗可调用的 toggle 桥。窗口保留原生边框与全屏行为，其他平台使用相同位置的常规图标。现有崩溃重开 P2 不属于本批，保持 open。

## Phase 2：设计

```text
+------------------+----------------------------------------+
| [关闭] [全屏]    |       拖拽区域                         |
|                  |                                        |
| [齿轮 通用]      | 通用                                   |
|   模拟器         | 说明                                   |
|   快捷键         |                                        |
|   关于           | 外观           [显示器][太阳][月亮]    |
|                  | -------------------------------------- |
|                  | 主题色                 [黄][蓝勾][绿]  |
|                  | -------------------------------------- |
|                  | 语言                 [简体中文 v]      |
|                  |                                        |
|   危险区         |                                        |
+------------------+----------------------------------------+
```

设置窗维持 760×560 / 最小 640×460；导航宽 176px、32px 顶部安全区、左右 8px、行高 36px、圆角 6px。详情内边距上 38px、左右 28px；最小窗沿用控件堆叠。外观图标有三语 aria-label/title；主题色为 28px 方块，选中外框与居中勾，不显示重复色名。全部业务按钮仍原生 disabled。

数据流：设置窗按钮 → preload `settings.toggleFullscreen()` → 主进程核对当前设置窗 sender → 切换本窗原生全屏。关闭沿用 close；不接受任意窗口 id，不新增文件或设备权限。全屏错误复用本窗现有错误区域。

文件：`SettingsWindow.tsx`、`settings/PaneGeneral.tsx`、`settings/SettingsParts.tsx`、`settings/copy.ts`、`settings/SettingsApp.tsx`、主进程 `window/settings.ts`、preload 与通道常量，以及对应窗口/renderer 测试。文档仅回写 DESIGN、stage 和 plan，参考图不复制进 book。

## Phase 3：实现

移除设置标题行与预览标记，顶部仅保留拖拽区域和两个窗口按钮。通用改齿轮，侧栏内缩并使用 6px 圆角；详情改为上 38px、左右 28px 留白。外观改图标分段，主题色改 28px 色块、外框与居中勾，保留三语名称和原生 disabled。

隐藏原生三灯，开启本窗原生全屏能力；新增当前设置窗 sender 白名单全屏桥。关闭与全屏错误均留在设置窗内，未新增业务写动作。

## Phase 4：验证

- 新断言先失败，实现后窗口与 renderer 相关 15 项通过；全量 806 项通过、6 项原有跳过。typecheck、lint、build 通过。

- 默认 760×560、最小 640×460；五分类、英文键帽、繁体与三主题亮暗样例均已核对。通用最小窗无横向溢出；业务控件全部 disabled；模拟器详情可滚到底（scrollTop = max = 207）。
- 检测只有三条 advisory，均为定制 macOS 红绿窗口控件的局部颜色；不扩展为产品业务颜色。临时样例入口与验证标签页已清理；截图仅留在 ignored 验证目录。
