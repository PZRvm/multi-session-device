# 关于页透明图标

## Step 0：需求简报

- 背景：关于页在非 Windows 平台仍显示带底板的图标，用户要求改用 resources 中已有的去背景版本。
- 需求：所有平台的关于页使用 `resources/icon-windows.png`。
- 范围：仅更换 `PaneAbout.tsx` 的图片引用与选择逻辑。
- 排除：不改系统、Dock、窗口和安装包图标，不重新生成图片，不改尺寸、布局、业务或依赖。
- 验收：关于页统一引用透明图片，保持 64×64；类型、lint、相关测试与构建检查通过。

## 阶段 1：分析

`PaneAbout` 当前按平台选图；Windows 已用透明资源，其余平台用带底板资源。已有 Windows 图标计划和图片确认可直接复用。影响仅限关于页展示，资源本身不变。

## 阶段 2：设计

只导入 `icon-windows.png` 为 `appIcon`，图片直接使用该引用。移除未使用的 platform 解构，保留父级传参兼容性；不修改任何接口或数据流。
