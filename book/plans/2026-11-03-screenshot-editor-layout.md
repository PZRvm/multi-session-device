# 图片编辑布局调整

## Step 0：需求简报

- 背景：用户反馈编辑页图标堆叠、左右功能区不居中，截图成功文本多余。
- 范围：截图编辑窗建窗尺寸、编辑工具条局部布局、截图结果气泡和相关测试。
- 排除：不修改绘图、裁剪、历史、导出、截图采集、缓存、剪贴板写入、其他窗口或设计系统。
- 边界：720px 指编辑窗口最小宽度，小图仍只缩不放；文字、马赛克、三语及成功反馈占位需要核验。
- 要求：编辑窗口初始及可缩放宽度均至少 720px；左侧功能区与右侧复制/下载按钮垂直居中；截图结果气泡去掉“已复制到剪贴板”文本，保留缩略图、保存、编辑和错误反馈。
- 授权：用户本轮指定三项修改并要求创建 worktree 开发，设计无待确认缺口，直接执行。

## 阶段 1：分析

影响链：main screenshotEditor 窗口下限 → renderer EditorShell 顶部工具带 → EditorToolbar 工具分组；主窗 ScreenshotPopover 消费 useScreenshot 的 copied 状态。

现状：窗口最小宽度 360px；topbar 与 toolbar 均允许换行，右侧操作区可能单独落行；成功气泡单独渲染复制文本。风险是 720px 下英文文字/马赛克标签以及编辑成功反馈仍可能占用宽度。

## 阶段 2：设计

- `src/main/window/screenshotEditor.ts`：最小宽度改为 720，保持图像显示缩放算法。
- `src/renderer/src/components/ScreenshotEditor/editorWrapper.ts`：顶部左右区保持同一 flex 行、垂直居中；左区按可用空间分组换行，图标不压缩；右侧按钮不挤压、反馈文本可收缩。
- `EditorToolbar.tsx`：只同步相关布局注释，工具逻辑不变。
- `ScreenshotPopover.tsx`：仅去掉 copied 分支的提示行，不改状态机或字典契约。
- 更新窗口、气泡及 DeviceToolbar 已有测试，使用真实 Electron renderer 验证几何位置。
- 数据流、IPC、权限和通知契约保持现有行为；无需新增接口、权限或系统通知。编辑器内部复制/下载结果提示保留。

## 反馈补充轮：左侧工具区水平居中

### Step 0

- 背景：用户指出上轮只有垂直对齐，左上工具区仍未水平居中。
- 范围：仅调整 EditorShell 内左侧 toolbar 的水平排列；沿用同一 worktree。
- 排除：不改右侧复制/下载位置、窗口下限、工具行为、画布、IPC 或截图反馈。
- 边界：居中基准是扣除原生三灯留位和右侧操作区后的左侧可用区域；换行时每行独立居中，按钮不压缩、不重叠。
- 要求：720px 与宽窗、不同工具和语言下，实际工具组在各行的中心与左区中心一致。

### 阶段 1 / 2：分析与设计

toolbar 已有 flex:1 和 align-items:center，但主轴仍为默认 flex-start，导致内容贴左。只增加 justify-content:center；不改变 topbar 或工具分组结构。布局不涉及新增权限、接口或通知。

验证从比较左右两个容器的纵向中心，补为比较左侧每行实际工具组与可用区域的横向中心，避免容器居中而内容仍贴左。使用真实 Electron renderer 复现并核验，无需为单条样式增加镜像单测。

## 反馈补充轮：原生窗口按钮上下居中

### Step 0

- 背景：用户再次反馈编辑页左上角功能区上下不居中。现有 renderer 工具区中心一致，但原生红黄绿按钮沿用 40px 标题栏的 y=12，与至少 48px 的编辑工具栏不匹配。
- 范围：本工作区截图编辑窗的 macOS 原生按钮定位，以及工具栏高度到该窗口的同步。
- 排除：不改其他窗口、画布、工具行为、复制反馈、端口和单实例机制。
- 边界：720px 下英文工具设置和成功反馈可触发换行，原生按钮需要跟随实际高度；Windows/Linux 不调用 macOS API。
- 要求：原生三灯与右侧按钮共用工具栏中线，单行、换行和恢复单行均成立；保留最小宽度与现有水平居中。

### 阶段 1 / 2：分析与设计

既有原生按钮实测经验确认灯中心约为 position.y + 8，48px 工具栏初始 y 应为 16。仅改固定 y 无法覆盖换行，因此由 EditorWindow 的 ResizeObserver 上报工具栏 border-box 高度，preload 增加一个只发送高度的方法，通道登记在共享常量中。编辑窗控制器使用自身 webContents.ipc 监听，只接收自身主 frame、有效且不超过窗口内容高度的值，按 round(height / 2 - 8) 定位。监听随 webContents 销毁，observer 随节点卸载断开。无需全局窗口控制接口、权限或通知变更。

验证包含原生按钮的真实单窗截图；capturePage 只用于 renderer 几何，不能作为原生按钮的验收证据。补主进程高度同步、非法高度和来源隔离回归，复用编辑器既有测试。
