# 图片编辑复审修复

## Step 0

- 背景：复审已复现页面缩放后原生三灯偏移、损坏元数据阻断显式端口覆盖及构建两项问题；用户要求修复。
- 范围：EditorWindow 的工具栏高度上报、截图编辑窗的原生定位、electron-vite 开发端口解析及对应测试。
- 排除：不改绘图、截图产出、其他窗口、单实例机制、README 和工作区分配规则。
- 边界：100%、125%、80% 及宽窗高度不变的缩放；元数据缺失、坏 JSON、null、错误类型和端口越界；构建不读取调试元数据。
- 验收：原生按钮与操作区中心差不超过 1 DIP；有效环境变量优先，无有效配置回退 6174；构建不受本地元数据影响。

## 阶段 1：分析

DOM 尺寸为 CSS px，主进程位置为 DIP；现有整数下限会拒绝缩放后的浮点尺寸。上报按高度去重也会漏掉高度不变的页面缩放。配置顶层无条件读取 JSON，优先级判断和构建模式都无法绕过异常。

## 阶段 2：设计

- 保留现有高度通道和本窗主 frame 校验；主进程读取可信的 getZoomFactor，将高度转换为 DIP 后定位，CSS 最小高度和 DIP 窗高分别校验，容纳亚像素误差。
- renderer 在工具栏 border-box 变化时上报，即使高度未变也保留宽度变化所触发的上报，以覆盖页面缩放。
- 配置改为按 command 延迟求开发端口：有效环境变量优先，其次读取并校验元数据，异常或非法端口回退 6174；build 不读元数据。合法端口为 1–65535 的整数。
- 无新增 IPC、权限或通知；观察器仍随节点卸载清理。
