# 1.0.2 发布

## 需求简报

M 级发布任务。用户授权合并 `dev → main`，并修复本次发布遇到的阻塞。当前 `1.0.1` 为 Preview，正式 Sparkle 公钥和私钥已配置。准备下一补丁版本 `1.0.2`，发布首个启用应用内更新的稳定版。

范围是 Windows 安装验证、版本和发布说明、稳定渠道变量、同仓库发布 PR、发布流水线及结果核验。保持当前签名密钥、历史 Preview 和既有发布触发条件。Windows 验收在独立的 CI 测试分支使用测试应用身份、数据目录和环回更新源。

## 分析与设计

- 当前 `dev` 已包含 Mac 更新、Windows NSIS、版本说明窗口及退出保护。`main` 仍指向 `1.0.1` 的发布。原计划的 Windows 真实安装交接需要进一步验证。
- 先用 Windows runner 安装测试版 `90.0.1`，确认更新后由 NSIS 替换为 `90.0.2`，核对重启与数据。在 `dev` 更新版本和说明，跑类型检查、lint、测试和目录索引检查。
- Windows 通过后设置稳定渠道变量，待 PR 检查完成后以 merge commit 合并。发布 Action 从精确合并 SHA 组装双方安装包、更新清单和签名 ZIP，验证草稿资产后公开。
- 以 GitHub 发布结果复核版本、Tag、合并 SHA、附件摘要与 Latest。现有 `1.0.1` 用户先手动安装一次。现场设备场景沿用原计划的验收边界。
